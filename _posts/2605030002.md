OpenCode는 터미널에서 쓰는 오픈소스 AI 코딩 에이전트다.
Windows에서는 공식 다운로드나 패키지 매니저 설치 중 하나로 시작하면 된다.

## 설치 전

가장 덜 헷갈리는 쪽은 공식 사이트에서 Windows 설치 파일을 받는 방식이다.
터미널 설치를 선호하면 `npm`, `scoop`, `choco` 같은 경로도 많이 쓴다.

## 설치

공식 사이트 다운로드 방식은 설치 파일을 받고 일반 프로그램처럼 진행하면 된다.
터미널에서 바로 설치하려면 아래처럼 간단히 갈 수 있다.

```powershell
npm i -g opencode-ai
```

또는 Windows 패키지 매니저를 쓰는 경우 아래처럼 진행할 수 있다.

```powershell
scoop install opencode
choco install opencode
```

## 처음 실행

설치가 끝났으면 프로젝트 폴더에서 실행한다.

```powershell
opencode
```

필요하면 초기 설정을 진행하고, 글들에서는 `/init`으로 시작 흐름을 잡는 예시도 같이 다뤘다.
API 키 연동이 필요한 경우도 있으니 실행 직후 안내를 같이 보는 편이 낫다.

## 확인

```powershell
opencode --version
```

- 명령어가 안 잡히면 새 터미널을 열고 `Path` 반영 여부를 먼저 본다.
- 설치 방식이 여러 개라 헷갈리면 하나만 골라서 끝까지 가는 쪽이 덜 꼬인다.
