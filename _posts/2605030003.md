Windows 터미널에서는 자주 쓰는 명령어만 알아도 작업 속도가 꽤 달라진다.
아래 정도만 익혀두면 폴더 이동, 파일 정리, 상태 확인은 대부분 처리된다.

## 이동/파일

- `dir` : 현재 폴더 내용 보기
- `cd 폴더명` : 폴더 이동
- `cd ..` : 상위 폴더로 이동
- `cd \` : 드라이브 최상위로 이동
- `mkdir 이름` 또는 `md 이름` : 새 폴더 만들기
- `rmdir 이름` 또는 `rd 이름` : 폴더 지우기
- `type nul > 파일명` : 빈 파일 만들기
- `copy 원본 대상` : 파일 복사
- `move 원본 대상` : 파일 이동
- `ren 기존이름 새이름` : 이름 바꾸기
- `del 파일명` : 파일 삭제
- `type 파일명` : 파일 내용 바로 보기

## 시스템

- `cls` : 화면 지우기
- `help` : 기본 도움말 보기
- `where python` : 실행 파일 위치 찾기
- `tree` : 폴더 구조 보기
- `more` : 긴 출력 나눠서 보기
- `find "문자열" 파일명` : 텍스트 찾기
- `exit` : 터미널 종료

## 네트워크/프로세스

- `ping google.com` : 네트워크 응답 확인
- `tasklist` : 실행 중인 프로세스 보기
- `taskkill /IM notepad.exe /F` : 프로세스 종료

공백이 있는 경로는 따옴표로 묶는 게 안전하다.
그리고 `ls`, `pwd`, `rm` 같은 건 CMD보다 PowerShell 쪽에 더 가깝다.
