uv는 Python 패키지, 가상환경, 버전 관리를 빠르게 묶어서 쓰기 좋다.
Windows에서는 설치만 끝내면 바로 프로젝트 시작까지 이어가기 편하다.

## 설치

가장 간단한 쪽은 PowerShell에서 설치 스크립트를 실행하는 방식이다.

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

스크립트가 막히면 GitHub Releases에서 Windows용 파일을 받아 원하는 폴더에 풀고, 그 경로를 `Path`에 추가하면 된다.
이 방식으로 설치했다면 보통 새 터미널을 한 번 다시 여는 게 편하다.

## 확인

설치 확인은 이 정도면 충분하다.

```powershell
uv --version
uv --help
```

바로 시작하려면 아래 흐름이 제일 무난하다.

```powershell
uv init
uv venv
.venv\Scripts\activate
uv pip install requests
```

## 막히면

- `uv`를 못 찾으면 터미널을 다시 열고 `Path` 등록부터 확인한다.
- 수동 설치였다면 압축 푼 폴더 위치를 다시 본다.
- 가상환경은 `uv venv` 후 `.venv\Scripts\activate`까지 해야 바로 쓰기 편하다.
